# ChatLog Viewer

**日本語** | [English](README.en.md)

## 概要
ChatLog Viewer は、ChatGPT などから出力した Markdown 形式のチャットログを読み返すためのビューアです。

主に [ChatGPT Exporter](https://www.chatgptexporter.com/) で出力した Markdown ファイルを想定しています。
手元の Markdown ファイルはブラウザ内で処理され、アプリ側から外部サーバーへアップロードされません。

長いログでも、検索や発言一覧から目的の話題へ移動できます。

## 使い方

公開ページを開き、読みたい Markdown ファイルを読み込んでください。

```text
ここにPages公開ページのURLを追記
```

### PCの場合

- Markdown ファイルを画面にドラッグ＆ドロップします。
- または、`Markdownを開く` からファイルを選びます。

### スマホの場合

- 上部バーのファイルアイコン、または `Markdownを開く` から Markdown ファイルを選びます。
- メニューを開くと、検索や発言一覧を使えます。

対応する拡張子は `.md` / `.markdown` です。

## 主な機能

- Markdown ファイルの読み込み
- ドラッグ＆ドロップ読み込み
- ChatGPT Exporterの `## Prompt:` / `## Response:` 形式を会話として表示
- コードブロック内を含む全文検索
- 検索結果の前後移動
- 発言者・種類による絞り込み
- 発言一覧からのジャンプ
- 標準、コンパクト、チャット風の表示切替
- ライト、ダークテーマ切り替えに対応
- PCモニターとスマホ縦長表示に対応

## 対応するMarkdown形式

主な対象は、ChatGPTの会話ログです。
前述の通り、 [ChatGPT Exporter](https://www.chatgptexporter.com/) の出力様式を
想定しており、それ以外の保証はしていません。
また、ChatGPT Exporterの仕様変更により表示が崩れる場合があります。

代表的な形式:

```markdown
## Prompt:

質問本文

## Response:

回答本文
```

既知の役割名が見つからない場合でも、繰り返し出てくる `## 任意の名前:` 形式の見出しをチャット風メッセージとして扱うことがあります。

それ以外の Markdown は、通常文書として表示します。

## プライバシーと安全性

- ローカルファイルはブラウザ内で処理されます。
- アプリ側からローカル Markdown を外部サーバーへアップロードしません。
- Markdown 内の HTML は実行せず、文字として扱います。
- `script`、`iframe`、任意HTML埋め込み、危険なインライン属性はサポートしません。
- URLから読み込んだ Markdown 本文は、Service Worker のキャッシュ対象外です。

## URL読込時の注意

Markdown URL の読み込みは、通常のブラウザ制限を受けます。

- `http:` / `https:` の Markdown URL に対応しています。
- 別ドメインのURLは、相手側サーバーがCORSを許可していないと読み込めません。
- 通常は、URL読込よりも手元の Markdown ファイルを選択、またはドラッグ＆ドロップして使う方法を推奨します。

## Markdown表示の制限

このアプリの Markdown 表示は、ログ閲覧向けの簡易レンダリングです。CommonMark 完全互換ではありません。

対応している基本要素:

- 見出し
- 段落
- 箇条書き、番号付きリスト
- 引用
- コードブロック
- インラインコード
- 安全なURLのリンク
- 簡易テーブル

生HTMLの表示・実行には対応していません。

## 対応ブラウザ

Chromium 系ブラウザで表示テストは行いました。
- Google Chrome
- Microsoft Edge

仕様上はスマホ・タブレットでも利用可能なはずです。
